# 05 — Verdict
## Q1. Is hardening the relay worth it? **BUILD FOR SELF — yes, small.**
Kill criteria check (00-idea.md): K1 fails to kill (18 of 61 attempts, 30%, were forced or aborted). K2 fails to kill (9/28 11:01 AM abort stranded the seat, inside 48 h; 9/28 packaging run died from an in-session Agent). K3 fails to kill (no detector for in-session agents, no verification the new claude launched, no handoff validation). Survives.
Cost is a few hours; value is the seat that runs the whole fleet unattended overnight (25-28 relays/day). Not a big build: one zsh file, ~150 lines of delta, plus a fake-pane harness. The main gain is not fewer forced exits (they cost ~1 min and lose nothing) but closing the two silent-loss paths (agents killed, wrong/empty handoff) and making the relay testable at all — it currently has zero tests and the only test bed is the live seat.
Fix priority: (1) refuse/hold on in-session agents, (2) handoff integrity + newest-handoff check, (3) verify new claude pid, (4) dialog handling that never sends bare Enter, (5) lock, dry-run, abort marker.

## Q2. Is it worth packaging for others? **Not as a standalone product. YES as #477 content + a small lead-magnet. Verdict: BUILD FOR SELF (content asset), not BUILD FOR MARKET.**
Evidence (02-market-proof.md): demand is real (Anthropic's own issues #43404 and #27914 asked for exactly this and were both closed "not planned", so the platform will not fill the gap soon) but supply is crowded at the handoff-DOC layer (at least 7 GitHub handoff plugins) with near-zero adoption (392fyc/claude-handoff: 1 star), and the one true unattended rotator (VNX/tmux `/clear` rotator) exists but is tmux-bound and buried in an orchestration system. Nobody found ships an idle-safe exit-and-relaunch of a fresh process (new binary/model) with input-box safety. That is a genuine but narrow differentiator, and the audience (people running Claude Code unattended in a terminal multiplexer) is small.
Synthetic-only enthusiasm would cap at SELF and there is no real-human signal here beyond GitHub issues. Reddit and YouTube-comment mining could NOT be done (reddit domains blocked to the search tool, Firecrawl errored) so the "real people asking" leg is issue threads only. Gap map: 06-gap-map.md.
Recommendation: story-first. #477's hook is the breakthrough (the seat that never dies; 55 handoffs in 43 h), the kit is a ~free GitHub gist/zip gated behind the email list (owned-list goal), not a paid product.
