# Build log

Built in one sitting on 2026-09-29: a local Jev-style typed decision model on gemma4 with token logprobs. The surprise was how little it took: `think:false`, one output token, `top_logprobs:20`, renormalize over A/B/C letters, done, about 100 lines of stdlib Python, and warm calls land in 150 to 600 ms. The first prompt I tried picked the wrong area for an obvious YouTube task until I added one-line option descriptions, so option `desc` is doing real work. The benchmark humbled it: on Adam's own 156 labeled tasks e4b scored 50.6%, 12b 55.8%, the existing forge-lane classify 42.9%. That looked bad until the confusion matrix showed the "wrong" answers were mostly Inbox (a catch-all, 0/25) and ClickUp-migrated labels, so the label noise, not the model, sets the ceiling; on clean areas it hit 21/25 to 24/25. The best beat for a video: the bigger model (12b) was slower by 2.6x, only slightly more accurate, and its confidence was useless (96% of answers above 0.8), while tiny e4b's confidence actually predicted correctness (57% right above 0.8 vs 17% below). Bigger is not better calibrated, and calibration is what makes a decision gate safe.
